Local Guardian registration API
GET /api/equipment: authenticated; metadata of all merged Center and Guardian equipment. No passwords or protected password blobs.
POST /api/equipment: authenticated Administrator only; same-origin and loopback restrictions apply.
JSON fields: nome, fabricante (Intelbras/Dahua/ONVIF), usuario, senha, modelo (optional), one or more of ip_interno/ip_externo/cloud; prioridade_conexao is a permutation of interno, externo, cloud; corresponding porta_http_interna/externa/cloud (default 80), porta_rtsp_interna/externa (default 554).
Cloud requires Intelbras serial. IP is host only. HTTP CGI/ONVIF discovery must succeed before any persistence. Discovered channels and RTSP port supersede browser guesses. Saves one profile per channel, maximum 64. Intelbras/Dahua discovery tries configured routes in priority order; WebRTC opening likewise retries routes after failed media opening. Existing established streams do not migrate automatically after failure: reconnect is required. ONVIF supports a single route. Service-port streaming, recording, timezone adjustment and editing existing registrations are not implemented. Unknown legacy ports stay null; the old route is used without inventing endpoints.
201: id, nome, canais, cliente_id, servidor_id, ativo. 400 invalid input/authentication at device/duplicate; 401 no Center session; 403 not Administrator/foreign origin; 415 wrong media type; 502 discovery failure.
Persistence: dguard-center-20261023/guardian-data/settings.json. Atomic Store save, device passwords protected with Windows CurrentUser DPAPI. Catalog merged with existing Center cameras at runtime; separate storage prevents an older desktop process overwriting browser registrations. Not synchronized into the desktop GUI's in-memory catalog.
Tests: Center.exe --registration-test uses a local authenticated CGI fixture and isolated storage. Real device credentials remain user-entered. Successful discovery does not establish video decoding.

PUT /api/equipment/{id}: Administrator only. Discovers configured device before atomic update. Null/empty senha preserves stored DPAPI password. Preserves equipment/camera IDs and recording plans. Failed discovery leaves original data unchanged. Legacy desktop entries receive local web overrides; merged catalog deduplicates camera IDs. Does not edit the original desktop settings file. Editing connection settings is now implemented; delete and enable/disable remain unsupported.

Local server assignment: GET/POST /api/local-servers; POST /api/local-servers/{id}/bind; GET /api/local-licenses. Administrator-only creation/bind/history. LOCAL-SV licenses identify this standalone installation, not production entitlements. Persisted atomically in guardian-data/local-servers.json with installation UUID. One server binding per installation; same-ID retry is idempotent; replacement rejected. Frontend maps local DVR ownership to the bound server. No remote enrollment, transfer, token issuance, service installation or production activation is implemented.
